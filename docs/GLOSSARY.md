# Vocabulary

| Term | Meaning |
|---|---|
| Script | Editable text to turn into speech, entered or imported from a text file. |
| Voice | A named set of imported or recorded reference audio clips for cloning. |
| Built-in voice | A voice packaged with the selected XTTS model. |
| Take | One generated WAV plus an immutable snapshot of its text, voice, model, seed and settings. |
| Queue | Takes waiting for or undergoing generation, processed one at a time. |
| Generate | Add takes to the queue and start processing. |
| Stop Queue | Stop the running take and cancel remaining queued takes. |
| Export | Copy the selected take to a user-selected location. |
| Reference audio | Speech recorded or imported to condition a cloned voice. |
