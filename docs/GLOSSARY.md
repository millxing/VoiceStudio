# Vocabulary

| Term | Meaning |
|---|---|
| Script | Editable text to turn into speech, entered or imported from a text file. |
| Voice | A named set of reference audio clips or saved XTTS conditioning for generation. |
| Built-in voice | A voice packaged with the selected XTTS model. |
| Clip | Generated or imported audio in the library. Generated clips retain their text, voice, model, seed and settings. |
| Queue | Clips waiting for or undergoing generation, processed one at a time. |
| Generate | Add clips to the queue and start processing. |
| Stop Queue | Stop the running clip and cancel remaining queued clips. |
| Export | Copy the selected clip to a user-selected location. |
| Reference audio | Speech recorded or imported to condition a cloned voice. |
| Cached voice | Saved XTTS conditioning tensors imported from a .pth file; contains no playable recording. |
| Saved speaker | One selectable voice inside a cached file that contains multiple speakers. |
| Appearance | System, Light or Dark display mode for VoiceStudio's windows. |
| Clips folder | Folder used for newly generated WAV files; existing clips retain their saved locations. |
| Timeline clip | A placed, trimmed section of a source clip on an editor track. |
| Imported clip | A WAV or MP3 copied into the library and decoded for editing. |

Persisted `takes`/`takeID` keys retain their original names for library compatibility.
